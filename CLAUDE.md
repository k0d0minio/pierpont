# pierpont

HORECA Pierpont Schedule Manager. A mobile-first PWA for one club, Pierpont Golf Course.
Reception publishes the programme of the day. The bar/restaurant (a separate business) reads
it and plans covers against it. Stack: Next.js 15 App Router, React 19, Supabase (Postgres),
Tailwind with Radix/shadcn primitives, `date-fns`. Copy in French and English. Deployed on
Vercel at `pierpont.vercel.app`.

The repo is superseded: `courseday` is the multi-tenant successor (Jamie, at adoption). Before
you build anything here, ask whether it belongs in `courseday`. The rules of this repo are in
`.icm/project-rules.md`. What the project is for is in `.icm/project.md`.
